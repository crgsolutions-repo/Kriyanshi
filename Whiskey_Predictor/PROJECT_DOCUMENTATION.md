# Whiskey Flavor Predictor - Project Documentation

## 1. Project Overview
This project involves the development of a Machine Learning-based predictive system designed to analyze and predict whiskey flavor profiles and overall quality based on production process parameters. The system utilizes historical data to train specific models for various flavor notes and a final quality category, accessible via an interactive Streamlit web application.

### Key Deliverables:
- **Data Processing Pipeline**: Automated cleaning, imputation, and feature selection.
- **Flavor Prediction Models**: 7 individual models predicting specific flavor notes.
- **Category Scale Model**: A master model predicting the final quality of the whiskey.
- **Flavor Intensity Quantification**: Algorithms to calculate and grade the strength of each predicted flavor.
- **Interactive Web App**: A user-friendly interface for simulating process changes and viewing real-time predictions.

---

## 2. Work Description

### Data Processing
- **Source**: `Final_output.xlsx`
- **Cleaning**: Handling missing numeric values via mean imputation.
- **Feature Selection**: Rigorous selection process involving ANOVA and VIF (Variance Inflation Factor) to identify the most impactful process parameters (`FINAL_FEATURES`).

### Modeling Approach
Two distinct types of models were developed:
1. **Flavor Models**: Independent Logistic Regression models for each of the 7 flavor profiles. These models use Principal Component Analysis (PCA) for dimensionality reduction (capturing 95% variance) before classification.
2. **Category Scale Model**: A LinearSVC (Support Vector Classifier) model that aggregates features from all flavor models to predict the overall quality category (Good/Bad).

### Application
A Streamlit-based web application allows users to:
- Adjust "Common Parameters" (affecting multiple flavors).
- Adjust "Unique Parameters" (specific to single flavors).
- View real-time "Present/Absent" status for each flavor.
- View the probability score (Intensity) for each flavor.
- See the Final Quality prediction with confidence levels.

## 3. Flavor Analysis: Absence/Presence & Intensities

The system analyzes 7 distinct distinct flavor profiles. For each flavor, a dedicated Logistic Regression model predicts its likelihood of appearing in the final product.

### Definitions
- **Absence/Presence**: Determined by comparing the model's **Probability Score** against a specific threshold.
- **Intensity**: The **Probability Score** (0.00 - 1.00) generated by the logistic regression model serves as the metric for flavor intensity. A higher probability indicates a stronger likelihood and intensity of the flavor.

### Flavor Breakdown

#### 1. Cereal/Grainy 🟤
- **Features Used**:
  - Wort initial gravity (25L Vessel)
  - SCREENING - below 2.2mm sieve 
  - Final Wash temperature_Fermentated Wash
  - Yeast Storage Temperature, deg C
  - Final Wash turbidity
  - Spirit Still temperature - Mean_Spirit_B (Max)
  - Wort receiver temperature
  - Low wine alcohol % obtained_Spirit_A
  - Wort final gravity (25L Vessel)
- **Threshold for Presence**: > 0.70
- **Model Accuracy**: Train 100% | Test 88%

#### 2. Fruity & Floral 🌸
- **Features Used**:
  - Mashing temperature
  - Temperature in Mashtun (Spezyme alpha NK)
  - Temperature in Mash-tun (Diazyme TGA)
  - Strength in PL_merge2
  - Set-up Wort pH
  - Wash distillation Rate - Mean
  - Final wash pH
  - Set-up wort gravity
  - 1st wort turbidity_Wort
  - Low wine turbidity Mean_Spirit_A
- **Threshold for Presence**: > 0.50
- **Model Accuracy**: Train 93% | Test 94%

#### 3. Fermented 🍺
- **Features Used**:
  - Set-up Wort pH
  - Wort final gravity (700L Vessel)
  - Malt foreign matter
  - Low wine alcohol % obtained_Spirit_A
  - Malt Hot water extract on dry weight basis (min)
  - Spirit distillation Rate - Mean_Spirit_B
- **Threshold for Presence**: > 0.50
- **Model Accuracy**: Train 93% | Test 94%

#### 4. Husky 🌾
- **Features Used**:
  - Spirit Still temperature - Mean_Spirit_B (Max)
  - Sparging water temperature
  - Wash condenser temperature(Max) - Mean
  - Weak wort output temperature
  - Grist Ratio on Milling - 1 Course
  - % Shelf life available Proteinase T 
  - Wash Still temperature(Max) - Mean
- **Threshold for Presence**: > 0.50
- **Model Accuracy**: Train 81% | Test 80%

#### 5. Starchy 🥔
- **Features Used**:
  - Strength in PL_merge2
  - Average ABV in FMS_Spirit_A
  - Draff loss
  - SCREENING - below 2.2mm sieve 
  - Recovery PL/Ton of Malt
  - Mashing temperature
  - Set-up Wort pH
  - Wort final gravity (700L Vessel)
- **Threshold for Presence**: > 0.40
- **Model Accuracy**: Train 68% | Test 69%

#### 6. Cooked 🍳
- **Features Used**:
  - % Shelf life available Optimash TBG
  - Wash Still temperature(Max) - Mean
  - Time of addition of Enzyme (Proteinase T)
  - Spirit condenser temperature - Mean_Spirit_B
  - Wort initial pH (2500L Vessel)

#### 7. Acidic/Solvent 🧪

  - Strength in PL_merge2

  - Mashing temperature
  - Low wine turbidity Mean_Spirit_B
  - Wort initial gravity 700 L

- **Model Accuracy**: Train 50% | Test 50%

## 4. Final Category Scale ⚖️

The **Category Scale** determines the overall quality ("GOOD" vs "BAD") of the predicted whiskey batch.

- **Model Used**: Linear SVC (Support Vector Classifier).
- **Features Used**: The union of all features listed in the flavor models above.
- **Decision Function**: The model calculates a decision function score, which is converted to a probability score using the sigmoid function: `prob = 1 / (1 + exp(-score))`.
- **Decision Threshold**: 0.76 (76% probability required for "GOOD").
- **Performance**: 
  - **Train Accuracy**: 70%
  - **Test Accuracy**: 67%

### Output Interpretation
- **Category Quality**: "GOOD" if Probability Score >= 0.76, else "BAD".
- **Confidence**: Displayed as the Probability Score (e.g., "The model is 85.0% confident...").
